# MarketPulse Insights

A modern sales and product analytics dashboard designed to feel like a real SaaS reporting tool.

## Features
- Executive dashboard layout
- KPI cards and trend visualization
- Segment performance and pipeline summary
- Recruiter-friendly business intelligence narrative

## Tech Stack
- React
- Vite
- JavaScript

## Run locally
```bash
npm install
npm run dev
```

Open: http://localhost:3000
